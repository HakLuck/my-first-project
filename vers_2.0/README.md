# Система Face Anti-Spoofing для предотвращения биометрического фрода

## 📋 Обзор проекта

Данный проект направлен на решение практической бизнес-задачи в сфере информационной безопасности — **защиту систем биометрической аутентификации (Face ID) от мошеннических атак предъявления (Presentation Attacks / Spoofing)**.

Мошенники часто пытаются обойти проверку лица, демонстрируя камере распечатанные фотографии (Print Attack) или видеозаписи с экранов планшетов и смартфонов (Replay Attack). Разработанная система реализует модуль **Liveness Detection**, который определяет, находится ли перед камерой живой человек или фейк.

### 🎯 Бизнес-цели

* **Снижение уровня фрода:** Минимизация рисков несанкционированного доступа к корпоративным системам и клиентским данным.
* **Высокая точность:** Достижение сбалансированных метрик классификации (F₁-Score ≥ 90%), чтобы избежать ложных пропусков злоумышленников и необоснованных блокировок легитимных пользователей.
* **Работа в реальном времени (Real-time Inference):** Обеспечение пропускной способности системы на уровне ≥ 30 FPS с минимальной задержкой (Latency) для сохранения бесшовного пользовательского опыта (UX).

## 🛠️ Архитектура и методология (Data Science Lifecycle)

Проект выполнен в рамках полного жизненного цикла Data Science и разделен на логические этапы:

1. **Исследовательский анализ данных (EDA) и Предобработка:**
   Анализ структуры анонимизированного датасета лиц, оценка распределения яркости и размытия с помощью `Pandas`, `Matplotlib` и `Seaborn`. Ресайз до 224x224, нормализация под стандарты ImageNet и стратифицированное разделение выборки на Train/Test (80/20).
2. **Сравнительное обучение моделей:**
   * *Модель №1 (Классическое ML):* **Random Forest** на «плоских» векторах изображений. Используется в качестве baseline-решения.
   * *Модель №2 (Глубокое обучение):* Кастомная нейросеть **AntiSpoofNet** на базе легковесной и производительной архитектуры **MobileNetV3-Small** для Edge-устройств.
3. **Оптимизация и развертывание (Inference Engineering):**
   Конвертация скомпилированного вычислительного графа PyTorch в промежуточный формат **ONNX** с последующей оптимизацией инференса на GPU через **NVIDIA TensorRT (FP16)**.

## 📊 Результаты работы

### 1. Качество классификации (Бизнес-метрики)

По результатам валидации на тестовой выборке глубокая сверточная нейросеть значительно превзошла классический ансамбль деревьев за счет эффективного извлечения микротекстур кожи, бликов бумаги и сетки дисплея:

| Метрика качества | Модель 1: Random Forest | Модель 2: AntiSpoofNet (PyTorch) |
| :------------------------------ | :---------------------------: | :------------------------------------: |
| **Accuracy**              |             0.82             |             **0.95**             |
| **Precision**             |             0.80             |             **0.96**             |
| **Recall**                |             0.81             |             **0.94**             |
| **F₁-Score (Macro)**     |             0.80             |             **0.95**             |

### 2. Производительность (Технические метрики бенчмарка)

Интеграция бэкенда ONNX Runtime с аппаратным ускорителем **TensorRT в режиме FP16** позволила добиться колоссального прироста скорости:

* **Процессор (CPU):** ~15–30 FPS (Задержка ~35.0 мс)
* **GPU + TensorRT (FP16):** **~500+ FPS (Задержка ~1.8 мс)**

Итоговые метрики тестов производительности автоматически сохраняются в файл `benchmark_results.csv` для проведения аудита.

## 🚀 Инструкция по запуску

### 1. Требования к окружению

Для сборки TensorRT-движка в облачной среде (например, Google Colab с подключенной T4 GPU) или локально выполните установку зависимостей:

```bash
pip install tensorrt onnxruntime-gpu torch torchvision scikit-learn pandas matplotlib seaborn pillow
```

### 2. Запуск пайплайна

1. Откройте файл `anti_spoof_pipeline.ipynb` в Jupyter Notebook или Google Colab.
2. Последовательно запустите ячейки:
   * **Ячейка 1-3:** Подготовка GPU-окружения, инициализация MobileNetV3 и автоматическая загрузка тестовых сэмплов.
   * **Ячейка 4:** Отрисовка графиков EDA (баланс классов и боксплоты признаков).
   * **Ячейка 5-7:** Обучение Random Forest и PyTorch-модели, вывод матриц ошибок и сводного отчета `classification_report`.
   * **Ячейка 8-9:** Экспорт в ONNX, компиляция TensorRT-движка, запуск бенчмарка скорости и автоматическое скачивание файла результатов `benchmark_results.csv`.
